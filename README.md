# testupsun

A minimal "Hello, World!" Python program.

## Requirements

- Python 3

## Usage

Run the program directly:

```bash
python hello.py
```

Expected output:

```
Hello, World!
```

The script defines a `main()` function guarded by an `if __name__ == "__main__"`
entry point, so importing it (`import hello`) prints nothing until you call
`hello.main()` explicitly.
