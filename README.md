# testupsun

A minimal "Hello, World!" Python starter program.

## Requirements

- Python 3 (no third-party dependencies).

## Usage

Run the program directly:

```bash
python hello.py
```

Expected output:

```
Hello, World!
```

The greeting lives in a `main()` function guarded by an
`if __name__ == "__main__"` entry point, so importing the module does not
print anything — call `hello.main()` explicitly if you need the greeting.
