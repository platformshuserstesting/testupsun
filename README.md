# testupsun

A small, self-contained Python test program.

## Requirements

- Python 3.8+

## Run the program

```bash
python main.py
```

This prints a deterministic greeting and a sample computation, then exits
with code 0.

## Run the tests

Install the test dependency and run `pytest` from the repository root:

```bash
pip install -r requirements-dev.txt
pytest -q
```
